The 32 x 32 PNGs preserve the original RGBA pixels. The 64 x 64 `@2x` PNGs
duplicate each source pixel into a 2 x 2 block for sharp Retina rendering.
Hotspots retain the original `.cur` coordinates at the base resolution.
